# Windscribe Record Cleaner

این ابزار رکورد محلی تشخیص چند حساب ویندسکرایب را از روی همین کامپیوتر پاک می‌کند.

## طرز استفاده

1. برنامه Windscribe را کامل ببندید (از آیکون کنار ساعت، **Exit**).
2. فایل `Windscribe-Record-Cleaner.bat` را اجرا کنید.
3. یک کلید بزنید و منتظر پیام `Record deleted.` بمانید.

هر دو فایل `.bat` و `.ps1` باید کنار هم در یک پوشه باشند.

## بکاپ

قبل از حذف، بکاپ خودکار در پوشه `backups` ذخیره می‌شود. برای برگرداندن، فایل `.reg` را دابل‌کلیک کنید.

## پارامترها

| پارامتر | کار |
|---------|-----|
| `-KillClient` | برنامه را خودکار می‌بندد |
| `-NoBackup` | بدون بکاپ حذف می‌کند |
| `-BackupDir` | مسیر بکاپ را تعیین می‌کند |

## نکته

این پاک‌سازی فقط محلی است و وضعیت حساب سمت سرور تغییر نمی‌کند.
